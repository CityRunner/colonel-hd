A small update to 1.0.0.

- `colonel-hd.ini` now names the three folders it uses, `game_folder =
  game`, `mt32_rom = rom` and `saves = saves`; a relative path is taken
  from the data folder (the folder of the ini). An empty value still means
  the same defaults, so existing files work as before.
- The first frame of the game no longer stalls at large scales: the frame
  is prepared before the game starts (at N = 10 this was the one frame
  over 16.7 ms in the whole game on a 2021 laptop).

Measured on that laptop (Ryzen 5 5600U, Radeon Vega graphics, Fedora 45,
Wayland) over the whole game with `--timing` (`docs/timing.md` in the
source): every frame within 16.7 ms at N = 1, 2 and 5, and at N = 10 all
but that first one; entering a room takes at most 0.19 s at N = 10; the
first launch analyses the pictures in 1.3 s; peak memory 238 to 622 MiB
by N. Not yet measured on Windows hardware.

Binaries for Linux (glibc 2.38 or newer) and Windows, x64 and ARM64.
Bring your own copy of the game: copy its files into `game/` of the
unpacked archive. See README.md in the archive.
